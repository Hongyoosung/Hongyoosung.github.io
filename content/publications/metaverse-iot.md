This paper proposes a system that enhances the data integrity of Internet of Things (IoT) devices in a virtual environment by combining Hyperledger Indy and MQTT.
This system complements the limitations of centralized systems by realizing a Decentralized Public Key Infrastructure (DPKI) structure utilizing a distributed network in pub/sub communication patterns.

To guarantee the data integrity of IoT devices, digital signature technology was applied. Furthermore, this paper presents a systematic method for secure and transparent data exchange in a virtual environment through communication scenarios involving four core elements—client, IoT device, broker, and blockchain—and a topic structure utilizing Decentralized Identifiers.
To verify the performance of the proposed system, this paper conducted experiments on four scenarios and evaluated communication performance in a virtual environment. The experimental results confirmed that the proposed system provides a reliable IoT data communication structure in a virtual environment.
