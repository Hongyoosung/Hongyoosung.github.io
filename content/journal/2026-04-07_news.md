### PlayGen-MoG: Framework for Diverse Multi-Agent Play Generation via Mixture-of-Gaussians Trajectory Prediction
**Link:** https://arxiv.org/abs/2604.02447

PlayGen-MoG introduces a groundbreaking framework for generating diverse and spatially coordinated multi-agent trajectories, particularly useful for team sports, from just an initial formation. It leverages a Mixture-of-Gaussians (MoG) output head with shared mixture weights across all agents, enabling the selection of a coherent play scenario that couples player trajectories. Key technical advancements include relative spatial attention for encoding pairwise player interactions and non-autoregressive prediction of absolute displacements, which eliminates cumulative error and removes the need for historical trajectory data.

This framework overcomes critical limitations of standard generative models that often struggle with posterior collapse or converging to the mean when generating diverse multi-agent behaviors. Its ability to produce distinct, coordinated plays from a static formation, without relying on observed history or accumulating prediction errors, is invaluable for robust system design. The shared MoG component is crucial for ensuring diverse yet plausible team-level strategies rather than just individual agent movements.

Engineers can deploy PlayGen-MoG to develop advanced sports analytics tools for generating and evaluating strategic plays (e.g., offensive schemes in football) or to create more realistic and varied AI behaviors in team-based video games. It also holds potential for other multi-agent coordination problems in robotics or simulation where diverse, spatially coherent movement plans are needed from an initial configuration, without extensive historical observations.

### Streaming Real-Time Rendered Scenes as 3D Gaussians
**Link:** https://arxiv.org/abs/2604.02851

This innovative approach streams real-time rendered scenes by continuously constructing and optimizing a 3D Gaussian Splatting (3DGS) model on a server. This evolving 3DGS representation, including full model snapshots and incremental updates, is streamed to remote clients. Clients then locally reconstruct the Gaussian model to render their current viewpoint, supporting advanced features like relighting and rigid object dynamics.

The significance of this technology lies in its ability to overcome the limitations of conventional 2D video streaming in cloud rendering. Unlike 2D streams that tightly couple content to a server-rendered viewpoint and restrict latency compensation to image-space warping, streaming a 3D representation dramatically improves viewpoint flexibility for latency compensation. It also enables more efficient amortization of server-side scene modeling across multiple users.

This technology is perfectly suited for enhancing cloud gaming and XR (e.g., VR/AR) applications, delivering more immersive and responsive experiences on resource-limited or heterogeneous client devices. It can effectively reduce motion sickness in VR/AR by enabling flexible client-side viewpoint rendering and facilitate shared, dynamically updated 3D environments for multiple users.

### Show HN: TTF-DOOM – A raycaster running inside TrueType font hinting
**Link:** https://github.com/4RH1T3CT0R7/ttf-doom

TTF-DOOM is a remarkable project that implements a DDA raycasting engine within a TrueType font's hinting virtual machine, exploiting its Turing-complete capabilities for 3D graphics rendering. A custom DSL compiler injects wall rendering logic into the font, dynamically repositioning glyph contours based on player coordinates supplied via font variation axes. JavaScript manages game logic and UI overlay, offloading the primary wall rendering computation to the font itself.

This project brilliantly demonstrates the unexpected computational power and Turing completeness of the TrueType font hinting VM, a ubiquitous yet often overlooked execution environment. It showcases ingenious solutions to severe constraints, such as unconventional fixed-point arithmetic, recursive function limitations for loops, and strict call stack limits, pushing the boundaries of what is conventionally understood as a "font." This work highlights the potential for repurposing embedded virtual machines and a deep understanding of low-level execution environments.

While primarily a technical demonstration, TTF-DOOM implicitly highlights broader engineering implications concerning embedded, Turing-complete VMs in common file formats. It can inspire highly creative, constraint-based programming challenges or novel approaches to digital art and interactive easter eggs within unexpected mediums. For security engineers, it underscores the importance of understanding the full capabilities of seemingly innocuous parsers and VMs for potential exploit vectors or unusual code execution environments.

### Show HN: Hippo, biologically inspired memory for AI agents
**Link:** https://github.com/kitfunso/hippo-memory

Hippo is a biologically-inspired memory system for AI agents that integrates decay, retrieval strengthening, and consolidation mechanisms to manage information effectively. It distinguishes between a persistent long-term memory (SQLite/markdown-backed) and a bounded, importance-based working memory layer to prioritize current context. Recall is enhanced with explainability, detailing how information was retrieved via BM25 or embeddings and its source context or confidence.

This project addresses the critical challenge of persistent memory and context transfer for AI agents, moving beyond simple storage to a more cognitive approach for managing agent knowledge. It allows agents to share learned experiences across diverse tools (e.g., Claude, Cursor, Codex), preventing repetitive errors and reducing the "cold start" problem for new sessions or different agents. Its portable, vendor-agnostic design with human-readable memory artifacts (markdown/YAML) simplifies integration and long-term maintenance within existing engineering workflows.

Engineers can use Hippo to build more intelligent and persistent AI agents that learn and retain information across sessions and tools, such as Claude, Codex, or Cursor. It's ideal for creating a shared, structured knowledge base for agent teams, mitigating repeated errors by decaying irrelevant information while reinforcing critical lessons from past tasks. Furthermore, it can organize and manage complex agent instructions (e.g., CLAUDE.md files) with automatic decay and confidence levels, making agent configurations more manageable and portable across projects without vendor lock-in.

### GrandCode: Achieving Grandmaster Level in Competitive Programming via Agentic Reinforcement Learning
**Link:** https://arxiv.org/abs/2604.02721

GrandCode is a pioneering multi-agent reinforcement learning (RL) system engineered to excel in competitive programming. It orchestrates various specialized agentic modules—including hypothesis proposal, solver, test generator, and summarization—and continually refines them through post-training and online test-time RL. A key innovation is Agentic GRPO, a novel RL algorithm specifically tailored to manage delayed rewards and mitigate off-policy drift prevalent in multi-stage agent rollouts.

This research marks a significant breakthrough: GrandCode is the first AI system to consistently outperform all human participants, including legendary grandmasters, in live competitive programming contests. It unequivocally demonstrates that AI can now tackle complex, multifaceted coding challenges requiring creativity and strategic thinking at a level superior to humans. This success validates the efficacy of sophisticated multi-agent RL systems for high-level cognitive problem-solving, a domain previously considered a human stronghold.

Engineers can adapt GrandCode's multi-agent RL architecture for automating complex software development tasks. This could encompass generating optimal solutions for intricate programming problems, automating the creation of robust test suites, or even intelligent code refactoring and bug detection. The system's ability to consistently generate high-quality, performant code could significantly accelerate development cycles and improve software reliability in specialized domains.
