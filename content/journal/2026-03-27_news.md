### Show HN: Fio: 3D World editor/game engine – inspired by Radiant and Hammer
**Link:** https://github.com/ViciousSquid/Fio

Fio is a brush-based CSG (Constructive Solid Geometry) 3D world editor and game engine developed in Python with a custom OpenGL/PyGame backend. It offers an immediate, "drop-in and play" editing experience, complete with real-time lighting and volumetric effects, alongside an entity I/O system inspired by Half-Life 2 for creating interactive environments. Designed for compactness and lightness, Fio targets platforms like Snapdragon 8CX and OpenGL 3.3, demonstrating the viability of building highly customizable, lightweight 3D engines primarily in Python. Its brush-based CSG workflow provides a rapid iteration alternative to traditional mesh-centric pipelines, ideal for architectural or "liminal" environment generation. Its modular, open-source Python codebase makes it a valuable tool for indie developers and researchers seeking a highly customizable engine for experimentation, bespoke tool development, or educational purposes in 3D graphics and game development, especially for lightweight, standalone applications.

### I built a real-time pipeline that reads game subtitles and converts them into dynamic voice acting (OCR → TTS → RVC) **Link:** https://www.reddit.com/r/MachineLearning/comments/1s40gtd/i_built_a_realtime_pipeline_that_reads_game/

This innovative project details a real-time machine learning pipeline that transforms game subtitles into dynamic voice acting. The system utilizes Optical Character Recognition (OCR) to extract text directly from the screen, which is then fed into a Text-to-Speech (TTS) model. Finally, a Real-time Voice Conversion (RVC) model applies a specific character's voice, delivering personalized voice acting with low latency. This robust integration of multiple complex AI models—OCR, TTS, and RVC—into a real-time system addresses significant challenges in model chaining, performance optimization for live inference, and managing computational resources. Practical applications range from enhancing game accessibility by providing dynamic voiceovers for unvoiced content to rapid content prototyping for animation, virtual assistants, or even dynamic AI character interaction in VR/metaverse environments.

### gumbel-mcts, a high-performance Gumbel MCTS implementation
**Link:** https://www.reddit.com/r/MachineLearning/comments/1s44vgv/p_gumbelmcts_a_highperformance_gumbel_mcts/

For complex decision-making tasks, a high-performance Gumbel MCTS implementation offers a significant leap forward. Gumbel MCTS enhances standard Monte Carlo Tree Search by incorporating Gumbel noise into the tree policy, balancing exploration and exploitation more effectively to bias searches towards potentially more rewarding outcomes. This technique leads to more efficient searches and superior decision quality. The "high-performance" aspect emphasizes crucial algorithmic and engineering optimizations, such as parallelization and efficient data structures, vital for maximizing speed and scalability. Senior engineers can deploy this powerful, computationally efficient algorithm in advanced AI for complex games (e.g., alongside deep reinforcement learning agents), robotics for real-time path planning and control in dynamic environments, or optimizing sequential decision-making in logistics, resource allocation, and autonomous systems where fast, high-quality decisions are paramount.

### ORACLE: Orchestrate NPC Daily Activities using Contrastive Learning with Transformer-CVAE
**Link:** https://arxiv.org/abs/2603.23933

Elevating the realism of digital environments, ORACLE is a novel generative model designed to synthesize realistic, non-repetitive indoor daily activity plans for Non-Player Characters (NPCs). This sophisticated model combines Transformers for processing sequential data, Conditional Variational Autoencoders (CVAE) for controllable generation, and contrastive learning for discriminative refinement. This hybrid architecture effectively tackles issues like imbalanced data and scarcity of training samples common in human activity datasets. ORACLE provides a robust framework for generating complex, context-aware sequential data, significantly enhancing agent behavior beyond traditional monotonous patterns, even with limited and imperfect training data. Its practical application lies in creating dynamic, believable NPC routines for highly immersive games and digital environments, or generating synthetic data for simulations requiring realistic sequential human behaviors in fields like smart home design, robotics, and crowd modeling.

### EVA: Aligning Video World Models with Executable Robot Actions via Inverse Dynamics Rewards
**Link:** https://arxiv.org/abs/2603.17808

Addressing a fundamental challenge in robot learning, EVA introduces a reinforcement learning post-training framework to align video generative world models with physically executable robot actions. This framework directly tackles the "executability gap," where visually plausible video rollouts might lead to infeasible control commands. EVA ingeniously repurposes an inverse dynamics model, trained on real robot trajectories, as a reward function to evaluate generated videos. This reward mechanism encourages smooth, kinematically consistent motions while penalizing actions that violate embodiment constraints, even if the generated videos contain visual artifacts. This approach improves the robustness and efficiency of robot world models by integrating executability as a training signal, ultimately reducing costly rejection sampling and enhancing downstream task success and safety. Senior Engineers can leverage EVA to improve the reliability and performance of robotic systems that use video-based world models for planning and control, particularly in tasks requiring precise and kinematically valid movements for complex manipulation, navigation, or interaction, ensuring generated action sequences are physically realizable and safe for deployment on hardware.
