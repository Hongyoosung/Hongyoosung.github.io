### Inkling: Our Open-Weights Model
**Link:** https://thinkingmachines.ai/news/introducing-inkling/

Inkling emerges as a significant player in the open-weights AI ecosystem, presenting a multimodal Mixture-of-Experts (MoE) transformer model. With a massive 975 billion total and 41 billion active parameters, coupled with an impressive 1 million token context window, Inkling has been extensively pretrained on 45 trillion tokens across diverse modalities including text, images, audio, and video. Its MoE architecture is meticulously designed to strike a balance between robust performance and efficient, controllable computational cost. This open-weights foundation empowers engineers with a highly customizable toolkit, enabling direct adaptation and extension of its multimodal reasoning capabilities. Its strategic MoE design and expansive context window are pivotal for deploying advanced AI systems efficiently and processing complex, long-form data. Practically, engineers can leverage platforms like Tinker to fine-tune Inkling on proprietary datasets, developing specialized AI agents or applications tailored to enterprise needs—such as bespoke intelligent assistants or sophisticated multimodal content analysis tools. The open-weights nature facilitates deep architectural modifications and seamless integration into existing ML pipelines for a wide array of real-world projects requiring adaptable, foundation model capabilities.

### Grok Build is open source
**Link:** https://github.com/xai-org/grok-build

SpaceXAI's Grok Build introduces an open-source, terminal-based AI coding agent implemented in Rust, promising to revolutionize the software development lifecycle. Operating as a full-screen Terminal User Interface (TUI), Grok Build intelligently understands codebases, edits files, executes shell commands, and adeptly manages long-running tasks. Its versatile agent runtime supports interactive use, headless operation for scripting and CI/CD pipelines, and even embedding into editors via its Agent Client Protocol (ACP). This project delivers a robust and extensible framework for deeply integrating AI into development workflows, offering unparalleled control over codebases and execution environments. The multi-modal operation ensures high flexibility for automation and developer tooling, while the Rust implementation guarantees performance and reliability. The ACP is a game-changer for custom tooling and editor integration, establishing Grok Build as a powerful platform for AI-assisted engineering. Senior engineers can swiftly deploy Grok Build using prebuilt binaries for interactive coding, automate tasks in CI/CD pipelines, or integrate it into custom IDEs. Installation is straightforward across Linux, macOS, and Windows, or it can be built from source, with comprehensive documentation available at docs.x.ai/build/overview.

### Running Gemma 4 26B at 5 tokens/sec on a 13-year-old Xeon with no GPU
**Link:** https://www.neomindlabs.com/2026/06/08/running-gemma-4-26b-at-5-tokens-sec-on-a-13-year-old-xeon-with-no-gpu/

In a remarkable feat of hardware optimization, an author successfully ran Google's Gemma 4 26B-A4B (MoE) on a 13-year-old dual Xeon E5-2690 v2 (Ivy Bridge) server—a system notably lacking AVX2/FMA3 instruction sets and a dedicated GPU. Achieving an impressive ~5.2 tokens/sec decode speed, this was made possible by adapting an optimized `ik_llama.cpp` fork, with crucial assistance from an AI agent (Claude) in re-routing hot paths to gracefully fall back on pre-AVX2 hardware. This achievement profoundly challenges the perception that modern AI demands cutting-edge hardware or expensive subscriptions, demonstrating that high-performance inference for large MoE models is attainable on extremely aged, GPU-less CPUs through meticulous software adaptation. It highlights advanced engineering prowess in understanding intricate model architectures and microarchitecture-specific optimizations, and powerfully illustrates the invaluable role an AI assistant can play in diagnosing and proposing complex code modifications for unsupported environments. This methodology allows enterprises to repurpose legacy servers for cost-effective local LLM inference, serving as a vital fallback for API downtimes or for batch processing where per-token costs are prohibitive. Engineers can leverage this approach to extend the useful life of existing hardware, fostering local, private, and offline AI capabilities without significant new investment.

### PoseAlign: Sculpting Pose-Consistent Meshes via Text-Guided Deformation
**Link:** https://arxiv.org/abs/2607.10560

PoseAlign introduces a sophisticated solution to a persistent challenge in 3D content creation: text-guided mesh deformation that rigorously maintains an object's original pose. This innovative technique employs a two-stage process: first, global pose scaling leverages the Laplacian as a differentiable mesh representation, enabling efficient and smooth deformation. Following this, fine-grained details are sculpted via a novel pose-aligned Score Distillation Sampling (SDS) loss, which integrates an attention-sharing mechanism to preserve the mesh's original pose while faithfully adhering to text prompts. The technical significance of PoseAlign lies in its ability to provide enhanced controllability in text-guided 3D mesh deformation, effectively balancing prompt adherence with critical pose preservation. For engineers, this translates into more robust and predictable outcomes when generating or modifying 3D assets, significantly reducing the need for manual post-processing to correct pose inconsistencies commonly encountered with existing text-guided methods. Practically, this technology can be seamlessly integrated into tools for rapid prototyping and content creation across gaming, animation, and virtual/augmented reality. Engineers can utilize PoseAlign to quickly generate pose-consistent variations of 3D characters or objects from textual descriptions, streamline design iterations, or create bespoke virtual assets where maintaining specific foundational poses—such as in character rigging or product visualization—is paramount.

### Spherical-GOF: Geometry-Aware Panoramic Gaussian Opacity Fields for 3D Scene Reconstruction
**Link:** https://arxiv.org/abs/2603.08503

Spherical-GOF presents an advanced omnidirectional 3D scene reconstruction framework built upon Gaussian Opacity Fields (GOF), specifically tailored for panoramic cameras. It ingeniously tackles pervasive distortion issues by performing GOF ray sampling directly on a unit sphere within a spherical ray space, thereby ensuring consistent ray-Gaussian interactions. The framework incorporates an efficient spherical bounding mechanism for precise ray-Gaussian culling and an adaptive spherical filtering scheme that meticulously accounts for panoramic pixel distortion. This work marks a significant leap in enhancing the geometric consistency of 3D reconstructions from omnidirectional cameras, addressing a longstanding challenge for current 3D Gaussian Splatting methods. By natively processing data in spherical ray space, Spherical-GOF bypasses the distortion and inconsistencies inherent in adapting perspective projections, leading to substantially improved depth and normal map accuracy and reducing depth reprojection errors by an impressive 57%. This advancement is crucial for robust spatial understanding in applications where wide field-of-view data is prevalent. Engineers can deploy Spherical-GOF for high-fidelity 3D scene reconstruction in diverse robotic applications, particularly those involving UAVs or ground robots equipped with omnidirectional cameras for environmental mapping, navigation, and inspection. Its superior geometric accuracy is indispensable for generating reliable digital twins, enhancing autonomous system perception, and creating immersive AR/VR content from panoramic captures where precise spatial relationships are critical.
